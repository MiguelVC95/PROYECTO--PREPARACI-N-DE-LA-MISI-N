# Misión Órbita – Avance 2: Ejecución de la misión

**Universidad:** CENFOTEC

**Período:** C3-2026  
**Integrantes:** Sharon Ávila, Miguel Vargas y Marcela Otárola

## Descripción

Misión Órbita es un proyecto académico desarrollado en Python. En el segundo avance se trabajan cuatro programas independientes relacionados con la ejecución de una misión espacial: selección del destino, simulación del viaje, exploración científica y evaluación del regreso y la supervivencia de la tripulación.

## Objetivos

- Aplicar estructuras condicionales y repetitivas de Python.
- Utilizar variables, operaciones, contadores y acumuladores para resolver problemas.
- Validar datos de entrada y mostrar resultados mediante la consola.
- Documentar el funcionamiento de los algoritmos con diagramas de flujo y casos de prueba.

## Programas incluidos

| Archivo | Descripción |
|---|---|
| `Ejercicio5.py` | Selección del destino y autorización de la misión según los recursos disponibles. |
| `Ejercicio6.py` | Simulación del viaje y del consumo de recursos durante el trayecto. |
| `ejercicio7_exploracion.py` | Exploración científica, administración de recursos y registro de resultados de la exploración. |
| `ejercicio8_regreso.py` | Evaluación del combustible para regresar, consumo de recursos durante el retorno y supervivencia estimada si la tripulación queda varada. |

Los programas se ejecutan **por separado**; no es necesario ejecutar los ejercicios anteriores para utilizar otro.

## Requisitos

- Python 3 instalado.
- Visual Studio Code u otro editor de código compatible con Python, o una terminal.

No se requieren bibliotecas externas para ejecutar los programas.

## Cómo ejecutar los ejercicios

1. Descargue y descomprima el archivo ZIP de la entrega.
2. Abra la carpeta `Codigo` en Visual Studio Code o en una terminal.
3. Ejecute el archivo correspondiente, por ejemplo:

   ```bash
   python Ejercicio5.py
   ```

4. Para los demás ejercicios, utilice:

   ```bash
   python Ejercicio6.py
   python ejercicio7_exploracion.py
   python ejercicio8_regreso.py
   ```

5. Ingrese los datos solicitados por cada programa y consulte los resultados en la terminal.

En algunos equipos con Windows, el comando para ejecutar Python puede ser `py` en lugar de `python`.
